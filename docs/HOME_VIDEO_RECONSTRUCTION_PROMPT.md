- 视频尺寸为竖屏手机，时长约 54.6 秒。
- 首页顶部依次为搜索框/分类按钮、可横向滚动的频道栏；推荐流纵向滚动时这两行保持在顶部。
- 频道顺序为：推荐、小说、听书、看剧、经典、短篇、漫剧、视频、知识；当前项黑色粗体，其余灰色。
- 推荐频道首屏包含白底圆角推荐榜，榜单为双列 1–8；其后为双列瀑布流，卡片图片比例不完全相同，并包含书荒广场、广告式大卡、图文动态等不同形态。

- 点击频道后先出现短暂居中加载态，再替换内容；回到首页时保持上次选择的频道和滚动上下文。
- 分类入口进入既有分类页；搜索入口进入既有搜索页，支持输入、清空、搜索结果分类栏和返回。

- 缺少原始封面资源时使用有明确层级的渐变/色块和书名文字，不新增不在视频中的页面。

## 实施要求

1. 优先复用 `HomeScreen.tsx`、`BookCover`、现有路由和 Mock 数据。
2. 使用响应式双列布局，目标内容宽度按 430px 手机画布计算；不得用只适配单一截图的绝对定位堆砌。
3. 所有可点击卡片必须有按下透明度/缩放反馈；频道切换动画控制在 180–260ms。
4. 搜索栏、频道栏、筛选项、榜单、瀑布卡片的字号、间距、圆角和颜色需分别与视频关键帧 4s、8s、12s、24s、34s、40s、44s、52s 对照。
5. 修改后必须执行 TypeScript、Vitest、Expo Web export，并在 430px 宽视口截图，与上述关键帧至少进行两轮视觉比较。
6. 不得覆盖用户已有未提交修改，不得 commit 或 push。
